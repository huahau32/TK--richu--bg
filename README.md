# TK--richu--bg

Windows 桌面小工具，共两个：

| 程序 | 用途 |
| --- | --- |
| 视频与Excel匹配工具.exe | 按序号把 MP4 文件名匹配到 Excel 数据行，导出可直接使用的发布表格 |
| 批量时间生成器.exe | 批量生成发布用的一批时间点，导出成文本/表格时间列表 |

下载：在本仓库根目录点击对应的 `.exe` 文件，选择 **Download raw file** 即可。

---

## 一、视频与 Excel 匹配工具

### 使用方法

1. 双击“视频与Excel匹配工具.exe”。
2. 首次运行时复制软件显示的机器码，向软件提供者获取卡密并完成激活。
3. 选择包含 MP4 视频的文件夹。
4. 选择源 Excel 文件（.xlsx 或 .xlsm）。
5. 选择结果文件保存位置。
6. 如需预约时间，勾选“填写预约时间”，设置第一个时间和每组个数。
7. 点击“开始生成”。

激活后，主程序右上角会显示当前卡类型和到期时间；永久卡显示“授权：永久卡”。

### 匹配规则

- 长文件名示例：`image62_7673852725507112977.mp4`
- 短文件名示例：`62.mp4`
- 分组文件名示例：`62（2）.mp4`、`62（3）.mp4`（也兼容英文括号）
- 连字符分组示例：`62-1.mp4`、`62-2.mp4`、`62-3.mp4`
- 下划线分组示例：`62_1.mp4`、`62_2.mp4`、`62_3.mp4`
- `image` 后面的数字或纯数字文件名会匹配 Excel 中相同【序号】的数据。
- 例如 `image62_7673852725507112977.mp4` 和 `62.mp4` 都会匹配序号 62。
- 分组文件名只使用括号前的数字匹配，括号内子序号忽略。
- 连字符分组只使用“-”前的数字匹配，“-”后的子序号忽略。
- 下划线分组只使用“_”前的数字匹配，“_”后的子序号忽略。
- 同一个序号如有多个视频，会为每个视频生成一行。

### 源 Excel 要求

表格中需要包含以下列：

- 序号
- 视频标题（也兼容“标题”“作品标题”“文案标题”）
- 产品ID（也兼容“商品ID”“Product ID”）

程序会自动在各工作表的前 50 行查找表头。

### 生成列

达人账号｜视频标题｜话题标签｜产品ID｜商品锚点｜AIGC｜发布方式｜预约时间｜视频名称

- 达人账号、话题标签、商品锚点统一留空；不勾选时间时预约时间留空
- 视频标题取 Excel 对应序号行的标题
- AIGC 固定为数字 1；勾选填写预约时间时发布方式为数字 2，不勾选时发布方式为数字 1
- 视频名称使用完整 MP4 文件名

### 自动填写预约时间

- 勾选“填写预约时间”后启用；时间直接写入原有【预约时间】列，不增加新列，表格始终保持原来的 9 列。
- 第一个时间必须填写为 `YYYY-MM-DD HH:MM`，可点击“填当前时间”。
- 时间总数自动等于本次成功匹配的行数，不需要手填组数。
- 默认每组 18 个，组内间隔 1 分钟；下一组第一个比上一组第一个晚 30 分钟。
- “高级设置”默认收起，可修改组内间隔和下一组组首间隔。
- 时间按匹配结果行顺序生成，跨午夜、跨月、跨年会自动进位。
- 导出的预约时间是严格的 `yyyy-MM-dd HH:mm` 文本，单元格格式为 `@`，【预约时间】列宽为 22。

### 检查报告

每次生成 Excel 时，同目录还会生成 `*_匹配报告.txt`，列出：

- 文件名格式无效的视频
- 视频有序号但 Excel 找不到的记录
- Excel 有序号但没有视频的记录
- Excel 中重复的序号

注意：旧版 `.xls` 文件请先用 Excel 另存为 `.xlsx`。

## 二、批量时间生成器

### 使用方法

1. 双击“批量时间生成器.exe”运行（首次启动稍慢属正常）。
2. 在界面中设置起始时间和生成数量等参数。
3. 按界面提示导出时间列表，粘贴到发布表格中即可。

> 具体参数项以程序界面为准。
